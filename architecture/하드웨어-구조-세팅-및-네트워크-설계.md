## 문서 목적

5대 Proxmox 물리 노드, 1G 관리망, pfSense VM, VLAN 대역, 10G 스토리지망의 IP 계획을 정리한다.

## 1G 물리 관리망

1G 관리망은 Proxmox 호스트 자체 관리, 라우터, 관리형 스위치, pfSense WAN 연결에 사용한다.

| 장비          | IP             | 용도                              |
| ------------- | -------------- | --------------------------------- |
| 라우터        | `172.16.30.1`  | 외부망/WAN uplink                 |
| 관리형 스위치 | `172.16.30.2`  | 1G 관리형 스위치 관리 IP          |
| pfSense WAN   | `172.16.30.3`  | pfSense 외부 인터페이스           |
| pve-1         | `172.16.30.11` | Proxmox 관리 IP                   |
| pve-2         | `172.16.30.12` | Proxmox 관리 IP / pfSense VM 배치 |
| pve-3         | `172.16.30.13` | Proxmox 관리 IP                   |
| pve-4         | `172.16.30.14` | Proxmox 관리 IP                   |
| pve-5         | `172.16.30.15` | Proxmox 관리 IP                   |

## pfSense 기본 구성

pfSense는 pve-2 위의 VM으로 구성한다.

| pfSense 인터페이스 | IP            | 설명                             |
| ------------------ | ------------- | -------------------------------- |
| WAN                | `172.16.30.3` | 라우터/1G 관리망 방향            |
| LAN                | `172.16.31.1` | pfSense 기본 LAN 대역 게이트웨이 |

pfSense LAN DHCP 대역은 `172.16.31.100-172.16.31.199`로 설정되어 있다.

다만 현재 설계에서는 실제 서비스망을 VLAN 10/20/30/40으로 분리해서 사용할 예정이므로, 기본 LAN 대역 172.16.31.100-199는 큰 의미가 없다.  
즉, 실질적인 VM/Kubernetes/서비스 IP는 아래 VLAN별 대역을 기준으로 잡는다.

## pfSense VLAN IP 대역

| VLAN    | 대역                          | 용도        | 설명                                         |
| ------- | ----------------------------- | ----------- | -------------------------------------------- |
| VLAN 10 | `172.16.41.100-172.16.41.199` | 공용망      | 외부 접근 서비스, LoadBalancer, Ingress 후보 |
| VLAN 20 | `172.16.42.100-172.16.42.199` | DMZ         | 외부와 내부 사이 중간 영역                   |
| VLAN 30 | `172.16.43.100-172.16.43.199` | 내부망      | Kubernetes node, DB, 내부 서비스 후보        |
| VLAN 40 | `172.16.44.100-172.16.44.199` | 관리자용 망 | Bastion, 관리 VM, 운영자 접근용              |

## VLAN Gateway 후보

각 VLAN의 게이트웨이는 pfSense에서 관리한다.

| VLAN    | Gateway 후보  |
| ------- | ------------- |
| VLAN 10 | `172.16.41.1` |
| VLAN 20 | `172.16.42.1` |
| VLAN 30 | `172.16.43.1` |
| VLAN 40 | `172.16.44.1` |

## 10G 스토리지망

10G망은 Proxmox/Ceph 스토리지 전용으로 사용한다.  
Kubernetes VM 서비스 IP는 10G가 아니라 pfSense VLAN 대역에 둔다.

| 물리 노드 | 10G IP        | Bridge | 용도           |
| --------- | ------------- | ------ | -------------- |
| pve-1     | `10.10.10.39` | vmbr1  | Ceph / Storage |
| pve-2     | `10.10.10.40` | vmbr1  | Ceph / Storage |
| pve-3     | `10.10.10.41` | vmbr1  | Ceph / Storage |
| pve-4     | `10.10.10.42` | vmbr1  | Ceph / Storage |
| pve-5     | `10.10.10.43` | vmbr1  | Ceph / Storage |

10G 대역에는 기본 게이트웨이를 설정하지 않는다.  
기본 게이트웨이는 1G 관리망 또는 pfSense VLAN 쪽에서 처리한다.

## 권장 VM / IP 배치안

### 관리자용 망 VLAN 40

관리 작업용 VM은 VLAN 40에 배치하는 것을 권장한다.

| VM         | IP 후보         | 용도                             |
| ---------- | --------------- | -------------------------------- |
| bastion    | `172.16.44.100` | SSH, kubectl, ansible, terraform |
| monitoring | `172.16.44.101` | Prometheus, Grafana              |
| argocd     | `172.16.44.102` | ArgoCD UI 관리 접근              |

### 내부망 VLAN 30

Kubernetes node와 DB는 내부망 VLAN 30에 두는 것을 권장한다.

| VM           | IP 후보         | 용도                     |
| ------------ | --------------- | ------------------------ |
| k8s-cp-1     | `172.16.43.100` | Kubernetes control plane |
| k8s-cp-2     | `172.16.43.101` | Kubernetes control plane |
| k8s-cp-3     | `172.16.43.102` | Kubernetes control plane |
| k8s-worker-1 | `172.16.43.110` | Kubernetes worker        |
| k8s-worker-2 | `172.16.43.111` | Kubernetes worker        |
| k8s-worker-3 | `172.16.43.112` | Kubernetes worker        |
| mariadb-1    | `172.16.43.160` | 운영 DB                  |

### DMZ VLAN 20

외부와 내부 사이에서 중계 역할을 하는 VM은 VLAN 20에 배치한다.

| VM            | IP 후보         | 용도                     |
| ------------- | --------------- | ------------------------ |
| lb-1          | `172.16.42.100` | HAProxy / Keepalived     |
| lb-2          | `172.16.42.101` | HAProxy / Keepalived     |
| reverse-proxy | `172.16.42.110` | Nginx reverse proxy 후보 |

### 공용망 VLAN 10

외부에서 접근해야 하는 서비스 IP는 VLAN 10에 배치한다.

| 항목         | IP 후보                       | 용도                       |
| ------------ | ----------------------------- | -------------------------- |
| ingress-vip  | `172.16.41.100`               | 외부 서비스 진입점         |
| metallb-pool | `172.16.41.110-172.16.41.130` | Kubernetes LoadBalancer IP |
| flaskapp-lb  | `172.16.41.110`               | FlaskApp Ingress           |
| argocd-lb    | `172.16.41.111`               | ArgoCD 외부 접근 필요 시   |
| grafana-lb   | `172.16.41.112`               | Grafana 외부 접근 필요 시  |

| 항목                    | 추천                                    |
| ----------------------- | --------------------------------------- |
| Proxmox vmbr0           | 1G 관리망, 172.16.30.x 대역             |
| Proxmox VLAN bridge     | VLAN aware 활성화                       |
| pfSense VM NIC          | WAN용 NIC 1개, LAN/Trunk용 NIC 1개 이상 |
| Kubernetes node IP      | VLAN 30 내부망 사용                     |
| Bastion IP              | VLAN 40 관리자망 사용                   |
| DB IP                   | VLAN 30 내부망 사용                     |
| MetalLB Pool            | VLAN 10 공용망 또는 VLAN 20 DMZ 중 선택 |
| 기본 LAN 172.16.31.0/24 | 사용하지 않거나 테스트용으로만 유지     |
| 10G 10.10.10.x          | Ceph/스토리지 전용, VM 서비스망과 분리  |
