### 진행 방식

- WBS를 기준으로 각자 역할에 맞는 작업 범위를 분석한다.
- 각 담당자는 설계 문서를 기준으로 본인 역할에 필요한 세부 일감을 정리한다.
- PM 역할을 맡은 팀장/부팀장이 이후 일감을 정리하고 세팅한다.
- GitHub Organization과 GitHub Project를 사용해 이슈 기반으로 작업을 추적한다.
- GitHub 사용이 익숙하지 않은 팀원을 위해 오늘 오후 GitHub 기초 특강을 진행한다.
