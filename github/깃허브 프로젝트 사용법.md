## 전체 그림
```
Issue #26 생성
↓
브랜치 생성
docs/issue-22-github
↓
문서 작업
↓
PR #23 생성
↓
다른 사람이 리뷰
↓
다른 사람이 Merge
↓
Issue #22 자동 Close
```
PR, Issue, 섞여서 번호 공간 (shared numbering)을 사용하므로 번호가 같이 올라감.
